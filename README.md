# Racha

مساعد ذكي عربي شخصي — يعمل على Android.

## المرحلة الحالية
Walking Skeleton (v1.0.0-skeleton)

## البناء
كل push على main يشغل البناء تلقائياً.
حمل APK من Actions -> آخر بناء -> Artifacts.


## حزمة الاستقرار

تتضمن هذه النسخة إصلاحات آلية لإدارة نموذج Qwen وتشغيل الخدمات الأمامية ومنع
الطلبات المكررة. يجب إنشاء Gradle Wrapper في بيئة البناء قبل تنفيذ الإصدار النهائي.
